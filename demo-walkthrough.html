✨ Key Features

  • Responsive Grid Layout - Cards automatically adjust to screen size
  • Search Functionality - Real-time filtering as you type
  • Detailed Profiles - View all 100+ data points per wrestler
  • Progress Visualization - All attributes shown with purple gradient bars
  • Regional Popularity - See popularity breakdown by country/state
  • Physical Condition - Track 6 body parts independently
  • 10 Wrestling Attributes - Comprehensive skill system
  • Statistics Dashboard - Roster analytics and top performers
  • Random Spinner - Animated wheel for random selection
  • Data Management - Export/Import via JSON files
  • localStorage Persistence - Data saved automatically
  • Hover Effects - Smooth animations throughout

🎯 How to Use

Step-by-Step Guide:

  1. Open the app - Click the link at the top of this page
  2. Load sample data - Click "Load Sample Data" button
  3. Browse roster - Scroll through the wrestler cards
  4. Search wrestlers - Type in the search box (try "Roman")
  5. View details - Click any wrestler card to see full profile
  6. Check statistics - Switch to Statistics tab for analytics
  7. Use spinner - Go to Spinner tab and click "Spin the Wheel!"
  8. Export data - Save your roster as JSON backup
